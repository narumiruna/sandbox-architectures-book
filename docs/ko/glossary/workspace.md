# Workspace

Workspace는 job이 사용할 수 있는 파일 모음이다. Checkout을 복제한 사본, 마운트된 디렉터리, 또는 입력 파일과 쓰기 가능한 임시 공간을 합친 형태일 수 있다.

예를 들어 worker는 Lamp 프로젝트의 일회용 사본을 편집하고, 원본 checkout은 sandbox 밖에 그대로 둘 수 있다. 쓰기 가능한 [mount](mount.md)는 결과가 다르다. Mount에 쓰면 원본 파일이 바뀔 수 있다.

[Workspace와 artifact](../practice/data-and-access/workspaces-and-artifacts.md)를 참조한다.
