# Host

Host は、[sandbox](sandbox.md) の外から Sandbox にリソースを提供するシステムです。[virtual machine](virtual-machine.md) では通常、VM を実行するマシンやオペレーティングシステムを指します。言語 Sandbox では、スクリプトエンジンを実行するアプリケーションを指すこともあります。*Host* は、特定の境界との関係で決まる役割の名前です。

## 例

ビルドサービスが、サーバー上で Linux [guest](guest.md) を実行します。Host は CPU 時間とメモリーを提供し、Host 側のファイルを VM のディスクの実体として使います。チームは、読み取り専用の [mount](mount.md) を通じてプロジェクトのディレクトリーを公開することにします。これにより、ビルドは Host 側のコピーを変更せずにソースを読み取れます。

## リソースとアクセス

Host 側は境界を設定し、それを越える手段を提供します。VM には仮想ディスクとネットワーク接続を提供する場合があります。スクリプト用の Sandbox には、プロジェクトのファイルを一つだけ読み取れる [host function](host-function.md) を提供する場合があります。こうした選択は Workload ができることを左右します。境界があるだけで、広いリソースアクセスの許可が安全になるわけではありません。

Host は必ずしも [control plane](control-plane.md) ではありません。Sandbox の配置先は Control plane が決め、実行は別のマシンが担う場合があります。設計で「Host」と書かれていたら、どの境界を指すか、実際にリソースを提供するのはどのコンポーネントかを確認してください。
