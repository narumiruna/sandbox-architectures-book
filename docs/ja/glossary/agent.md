# Agent

Agent は、AI モデルで次の行動を決め、ツールを呼び出して実行できるシステムです。Agent はモデルにスクリプトの作成を頼めますが、そのスクリプトは Agent が実行する作業の一部にすぎません。そのスクリプトを Sandbox に入れても、Agent の他の部分まで同じ Sandbox に入るわけではありません。

## 例

Agent がプロジェクトの進捗報告を作ります。モデルに、Issue のタイトルを調べてラベル別にまとめるスクリプトの作成を頼みます。スクリプトは、Issue を検索する [tool](tool.md) だけを呼び出せる [sandbox](sandbox.md) で実行されます。モデルを呼び出すアプリケーションも、Issue の検索を処理するサービスも、そのスクリプト用の Sandbox の外で動きます。

## Agent が実行するもの

Agent はモデルにタスクを渡し、要求されたツールを実行し、次の判断のためにその結果をモデルへ返せます。ツールを一度に一つずつ呼び出すことも、[Code Mode](code-mode.md) を使って生成したスクリプトに複数回の呼び出しを行わせ、結果をまとめさせることもできます。

別の設計では、Agent のアプリケーション自体と、そこから起動するローカルコマンドを Sandbox 内で実行します。この二つの設計を区別するには、それぞれの [isolation boundary](isolation-boundary.md) でどのコードが [workload](workload.md) なのかを確認します。境界の外にあるツールハンドラーは、境界の内側から要求を受けた場合でも、自身の権限で動きます。
