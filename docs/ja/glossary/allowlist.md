# Allowlist

Allowlist は、プログラムが使ってよいリソースや実行してよい操作を列挙するものです。信頼できるコンポーネントが要求を照合し、リストに合わない要求を遮断するときにだけ、アクセスを制限できます。

## 例

ビルド用の Sandbox がソフトウェアパッケージをダウンロードする必要があります。その [policy](policy.md) では、チームのパッケージミラー（パッケージのコピーを保管するサーバー）への [egress](egress.md) 接続だけを許可します。新しい接続のたびに確認を行うネットワーク制御がリストを適用します。リストだけでは通信を遮断できません。

## ルールで確認できる項目

ルールの範囲は、確認を行うコンポーネントから何が見えるかによって決まります。接続ルールは接続先とポートを照合できます。Web リクエストの内容を読み取って転送するサービスであれば、操作とパスも確認できます。[OpenShell v0.1.9 のネットワークルール](https://github.com/NVIDIA/OpenShell/blob/v0.1.9/docs/how-it-works/policies/network-rules.mdx#connection-and-request-checks)では、この二段階の確認を例示しています。

サービスへの接続を許可するだけでは、Workload が何を送れるか、サービスが何の操作を受け付けるかは制限されません。Workload に一つの操作しか必要ない場合、[least privilege](least-privilege.md) のためには接続先だけでなく操作も照合します。制限の対象となるアクセスは、必ずルールを適用するコンポーネントを通るようにします。一つの経路で確認しても、別の経路には適用されません。
