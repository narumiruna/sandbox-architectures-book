# Workspace

workspace は、ジョブが作業に使えるファイルの集まりです。チェックアウトのコピー、mount したディレクトリ、または入力と書き込み可能な一時作業領域の組み合わせが該当します。

たとえば worker は、元のチェックアウトを sandbox の外に残したまま、Lamp プロジェクトの使い捨てコピーを編集できます。書き込み可能な [mount](mount.md) では事情が異なり、そこへの書き込みで元のファイルが変わる場合があります。

「[workspace と artifact（英語）](../../practice/data-and-access/workspaces-and-artifacts.md)」を参照してください。
