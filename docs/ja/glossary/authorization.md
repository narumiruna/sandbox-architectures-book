# Authorization

Authorization とは、身元が判明している呼び出し元に対し、特定のリソースへの操作を許可するかどうかを判断することです。まず呼び出し元が誰であるかを確認しますが、身元が分かっただけではアクセスは許可されません。

## 例

スクリプトは Issue を検索する [tool](tool.md) を呼び出して `LAMP-17` を読めますが、別のプロジェクトの Issue は読めません。ツールは要求を受けるたびに、身元が判明している呼び出し元の権限と、指定された Issue を確認します。要求の項目に別のプロジェクトを指定しても、権限の証明にはなりません。

## 確認が必要な場面

呼び出し元に代わってデータを返したり変更を加えたりできる操作では、Authorization の確認が必要です。[sandbox](sandbox.md) でスクリプトが呼び出せるツールを制限していても、呼び出し元に何が許可されているかはツールごとに確認します。具体例は[ツールの Authorization（英語）](../../practice/design/tool-authorization.md)を参照してください。
