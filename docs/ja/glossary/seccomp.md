# Seccomp

seccomp は、プログラムが kernel に送る要求である [system calls](system-call.md) をフィルタリングできる Linux の機能です。特定の種類の要求は遮断できますが、seccomp だけでパス名に基づくファイルアクセス規則を適用することはできません。

## 例

文書変換用の sandbox は、seccomp を使ってネットワークソケットの作成要求を遮断できます。作成だけを遮断しても、プログラムがすでに持つソケットの使用は制限されません。変換プログラムが入力を読み取る場所と結果を書き込む場所は、別のファイルシステム policy で制限します。

## フィルターが検査できるもの

[Linux の seccomp フィルターの文書](https://docs.kernel.org/userspace-api/seccomp_filter.html)によると、フィルターは system call 番号と引数の生の値を検査できます。呼び出しを許可することも、たとえば実行せずに失敗させることもできます。`openat` などの呼び出しに渡すファイルパスは、プログラムのメモリに格納された文字列です。フィルターが見られるのは文字列のアドレスであり、文字列そのものではありません。

見えるファイルは [mounts](mount.md) で制御し、それらに対する操作はファイルアクセス規則で制御してください。[control group](control-group.md) の役割はそれらと異なり、リソース使用量の測定や制限を行います。
