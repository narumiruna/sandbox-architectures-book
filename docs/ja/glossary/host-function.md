# Host function

Host function は、言語 Sandbox の外に実装され、その中のコードから呼び出せる操作です。どの関数を公開するかは、Sandbox を実行するアプリケーションが決めます。関数は、呼び出し元のスクリプトの権限に限定されず、関数を実装するコンポーネントの権限で実行されます。

## 例

[sandbox](sandbox.md) 内のスクリプトが、あるプロジェクトのバージョン番号を必要としています。アプリケーションは、そのプロジェクトの manifest からバージョンを読み取り、バージョンを表す文字列だけを返す Host function を公開します。スクリプトは、プロジェクトのファイル全般へのアクセス権を受け取らなくても、その値を取得できます。

## 境界を越える呼び出し

言語の Runtime は、外側のアプリケーションを呼び出す手段を提供します。たとえば、[WebAssembly](webassembly.md) モジュールは、アプリケーションが *import* として供給する関数を呼び出せます。これはモジュールの外から提供される操作です。[Wasmtime のセキュリティドキュメント](https://docs.wasmtime.dev/security.html#webassembly-core)では、import を明示的に提供することで、モジュールが独自のメモリーの外側で何をできるかをアプリケーションが制御できる仕組みを説明しています。

[tool](tool.md) は Agent やスクリプトに提供する操作です。Host function は、その操作を言語 Sandbox から呼び出せるようにする手段の一つです。時計などの基本サービスを提供する Host function もあります。どちらの場合も、ハンドラーは入力、操作の影響、返すデータに対して、該当する [policy](policy.md) を適用する必要があります。スクリプト自体の制限は、その代わりにはなりません。
