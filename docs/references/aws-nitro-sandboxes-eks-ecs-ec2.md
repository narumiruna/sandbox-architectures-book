# Introducing AWS Nitro Sandboxes for EKS, ECS, and EC2 (November 2026)

[Original source](https://aws.amazon.com/about-aws/whats-new/2026/11/nitro-sandboxes-eks-ecs-ec2/)

## Content

Announces hardware-isolated VMs managed by the Nitro Hypervisor for individual EKS pods or ECS tasks and for workloads launched directly on EC2.
