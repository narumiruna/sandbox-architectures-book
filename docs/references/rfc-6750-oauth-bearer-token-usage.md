# RFC 6750: The OAuth 2.0 Authorization Framework: Bearer Token Usage

[Original source](https://www.rfc-editor.org/rfc/rfc6750.html)

## Content

Defines how a holder of a valid bearer token can access protected resources over HTTP, including by sending the token in the Authorization header.
