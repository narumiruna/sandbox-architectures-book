# Gondolin Snapshots (v0.14.0)

[Original source](https://github.com/earendil-works/gondolin/blob/v0.14.0/docs/snapshots.md)

## Content

Documents Gondolin's disk-only checkpoints. Creating a checkpoint stops the original VM. Restoring boots a new VM from the captured root disk without restoring RAM, processes, VFS mounts, or files on tmpfs.
