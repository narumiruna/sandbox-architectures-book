# Amazon Bedrock AgentCore Runtime V2 becomes the default (November 2026)

[Original source](https://aws.amazon.com/about-aws/whats-new/2026/11/new-agentcore-runtime-default/)

## Content

Announces that new runtimes in supported regions default to V2, which restores each session in its own Firecracker microVM from a snapshot of the initialized agent.
